# CableCheck Dataset

## Dataset Description

This dataset contains annual reports from Polycab India Limited.

The reports will be used for the CableCheck GenAI project to
research electrical cables, manufacturers, and procurement-related
information.

## Data Storage

Full PDF reports are stored locally in `data/raw/polycab/`.

The full reports are not committed to GitHub.

The dataset manifest is stored in `data/manifest.csv`.
